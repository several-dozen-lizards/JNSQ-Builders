# JNSQ Builders 0.1.2 preview

Includes the complete 0.1.1 refresh of both editors, plus the latest grass, terrain, rock and stone-surface refinements captured on 2026-09-12.

New installation: download Get-JNSQ-Builders.zip and run its helper with Python 3.10+ on PATH. All base assets and both updates are retrieved and verified automatically. Then run INSTALL_BUILDERS.bat and START_BUILDERS.bat. Allow 55 GB free.

Existing 0.1.0 installation: close the editors, back up data, extract the 343 MB update from the 0.1.1 release and this 0.1.2 update into the same parent folder as JNSQ-Builders, then run INSTALL_BUILDERS.bat. Existing 0.1.1 installations need only this small update. Saved data is not included in either ZIP.

0.1.1 update: https://github.com/several-dozen-lizards/JNSQ-Builders/releases/download/v0.1.1-preview/JNSQ-Builders-0.1.1-update-01.zip

65 avatar starting models and all current world assets are included. New hair previews/sources are bundled; first-use fitting still requires the separate Blender/MPFB tools. The main JNSQ public build is unchanged.

Validation includes copied-package tests, actual wardrobe exchange preserving 187 head/face shape targets, world-editor tests, source/asset parity and update-data preservation. Fresh visual rendering could not be verified because the current in-app browser reports WebGL2 unavailable.
