# Builders 0.1.1 preview

Includes the current avatar models, face/neck controls, wardrobe exchange that preserves the character, hair rendering and avatar preview export. World changes include lighting/water, first-person editing, ribbon navigation and furniture improvements. The fish tank asset is refreshed.

Existing 0.1.0 installation: close the editors, back up your data folder, and extract the update ZIP(s) into the same parent folder as JNSQ-Builders. Run INSTALL_BUILDERS.bat again. Your data folder is not part of the update.

Fresh installation: use Get-JNSQ-Builders.zip. The helper downloads the original packs followed by this update automatically. Old source models may remain available on disk; the current starter menu and manifest define this version.
