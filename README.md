# JNSQ Builders

Local Avatar Creator and World Builder, released separately from the JNSQ household.

**[Download and installation](https://several-dozen-lizards.github.io/JNSQ-Builders/)**

Windows preview. Python 3.10+ and a WebGL-capable browser are required. No model API key,
resident setup, Blender or Godot editor installation is needed for prepared assets.
The complete asset library is distributed through Releases; this source checkout
alone does not contain the large model/renderer files. Download the full bundle to run.

The bundle includes 63 avatar starting models, 100 world models, textures and previews.
Saved work stays in the installation's data folder. Additional hair fitting requires
the separate Blender/MPFB authoring tools; this preview offers prepared choices.

See THIRD_PARTY_NOTICES.md and ASSET_REVIEW.json for component credits and the
documented gaps in historical asset provenance. Retain notices when sharing assets.

Validation: copied-package API tests, rendered avatar/island previews, local save/reopen,
and a clean dependency installation. Preview status means bugs may remain.
